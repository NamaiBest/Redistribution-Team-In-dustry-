Data used: FreshRetailNet-50K (Dingdong-Inc), public on Hugging Face:
https://huggingface.co/datasets/Dingdong-Inc/FreshRetailNet-50K

The full training file (4.5M rows, ~106 MB) exceeds the 10 MB upload limit.
freshretailnet_sample_city0_20stores.csv is a sample (city 0, 20 stores, all 90 days, daily columns).
The notebook and run_analysis.py download the full data directly.
